# 窗口置顶与边缘迷你模式

Pomolet 采用原生 macOS SwiftUI / AppKit 窗口；此次按 Operate 模式扩展现有交互，保留奶油纸、绿色强调色及深色黑白风格。窗口状态独立于计时会话，切换形态不重置计时。

## 形态与视觉

- 完整内容为 **390 × 420 pt**，四周各 **28 pt** 透明边距，窗口总尺寸 **446 × 476 pt**。
- 迷你计时条为 **320 × 76 pt**，位于 **336 × 128 pt** 透明窗口内的 `(8, 44)`；人物在左侧 **76 × 104 pt** 区域显示，头部露出计时条上方。外围留白与人物视频背景透明；18 pt 圆角、细描边、轻阴影，不显示底部进度线。
- 迷你模式不显示模式标题，保留透明 IP 人物、垂直居中的等宽数字倒计时、开始 / 暂停、展开及图钉按钮。人物在计时运行且窗口可见时播放所选模式动画，暂停、隐藏或减少动态效果时停止；拖动人物或文字区域均可移动窗口；完整窗口顶部有专用拖动区域。

## 置顶与操作入口

- 两种形态共用同一个图钉状态，均以 `pin` / `pin.fill` 表示关闭 / 开启，辅助文字随状态更新；菜单勾选同步。完整形态的选中图钉使用强调色，迷你图钉保留次要色。
- 开启置顶使用 AppKit `.floating` 层级，关闭恢复 `.normal`；吸附本身不自动置顶。置顶偏好保存为 `windowAlwaysOnTop`。
- “窗口 → 窗口置顶”：**⌘⌥P**；“边缘吸附”默认为开启，保存为 `windowEdgeSnap`，关闭时立即展开迷你窗口。
- 迷你展开按钮、“窗口 → 展开完整窗口”及迷你模式下 **Esc** 均可展开。打开设置（**⌘,**）、统计（**⌘2**）或番茄钟（**⌘1**）也会先展开。
- **⌘Return** 开始 / 暂停，**⌘R** 重置；无编辑器和控件焦点时，空格可开始 / 暂停。快捷键属于应用内操作。

## 吸附、恢复与多屏几何

- 拖动时以内容可见边界计算距离，排除透明边距；完整窗口进入工作区任一边 **40 pt** 内、迷你窗口进入 **36 pt** 内时，只预备吸附，不切换形态。跨过边界后的溢出同样有效，无论溢出多少都保持预备；只有往屏幕内侧拖离退出范围才取消。当前显示器由拖拽指针选定，窗口完全溢出也会回收到该显示器边缘。最终形态在松手时决定：完整窗口确认吸附后进入迷你模式，并回到番茄钟页。
- 迷你窗口松手确认吸附后贴边；拖离取消预备，松手后围绕拖动后位置展开。主动点击展开则优先恢复此前完整窗口位置，再限制到工作区内。
- 工作区使用 `NSScreen.visibleFrame`，避开菜单栏与 Dock。跨屏拖动优先选择鼠标所在显示器，展开时选择与锚点重叠面积最大的显示器；坐标采用 AppKit 左下角原点，支持负坐标布局。
- 屏幕参数变化时，迷你窗口按已记录边缘重新吸附；完整窗口限制在当前可用工作区内。透明边距允许位于工作区外，内容保持可见。

## 预吸附反馈

- 按住拖动进入吸附范围时，边缘出现 **2 pt 宽、28 pt 长**的细标，并播放一组 **290 ms** 的牵引回弹，位移依次为 **3.2 → −1.0 → 0.28 → 0 pt**，并配合三层扩散边缘场线与较强的吸引缩放。松手确认后才播放下述液体形变；普通点击不提交吸附。预吸附细线独立于窗口材质的回弹变换，只对可见性做淡入淡出；松手进入形变时立即移除，并停止残余回弹，避免窗口切换到过渡画布时发生漂移。
- 进入预备后，退出阈值额外增加 **20 pt**，即完整窗口 **60 pt**、迷你窗口 **56 pt**；角落附近保持当前预备边，避免反复切边，反馈冷却为 **350 ms**。拖离退出范围即取消；已停靠的迷你窗口拾起时不重复触感。
- 触感调用原生 `NSHapticFeedbackManager` 的 `alignment` 双段反馈（间隔约85ms）。支持触感的 Force Touch 设备可提供物理反馈，普通鼠标只有视觉反馈；尚未确认真实触感与主观手感。

## 磁性过渡

- `Sources/WindowDockAnimation.swift` 使用单一连续轮廓，仅吸附收起时形成朝向边缘的窄液体颈部；小窗展开为大窗口时保持平滑轮廓，不出现液体凸起。完整与迷你内容交接时，共享倒计时持续显示，轮廓、位置和字号使用同一解析阻尼弹簧响应。吸附时长 **0.64 秒**，展开时长 **0.56 秒**。
- 过渡期间，原生窗口临时覆盖起止窗口的包围区域并额外留白，避免形变被裁切；结束后恢复目标形态的实际窗口尺寸。系统开启“减少动态效果”时直接切换。
- 动画中通过菜单或 Esc 请求展开，以及打开设置 / 统计的请求，会排队衔接到过渡终点，避免中途跳变；revision 隔离旧计时回调，防止旧动画覆盖新状态。
- 播放中从小窗展开时，大窗首帧就按播放布局初始化：人物、时钟、工具栏和底部按钮直接进入播放样式；不会先闪过暂停布局。已开始会话的液体按钮也直接恢复到分离状态。
- 已通过 **574 项几何与动效检查**；原生离屏拖拽的 **7 项断言**覆盖按住不提交、离开取消及点击无误触发，parity 检查共 **92 项**（新增 32 项原生像素渲染断言，覆盖四边、两种尺寸下的细线锚点和形变交接残留）。已实测浅色暂停态的吸附 / 拖离，以及深色运行态的吸附 / 展开，运行态计时持续。物理多屏场景仍未验证。

## 验证边界

多屏布局目前只通过几何测试验证，尚未进行物理多显示器拖动、插拔或不同缩放比例的实机验证；真实触感与主观手感亦未验证。上述实现描述不代表这些场景已验收。行为来源：`Sources/WindowPresentation.swift`、`Sources/WindowDockGeometry.swift`、`Sources/App.swift`、`Sources/RootView.swift`。
