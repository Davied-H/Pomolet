# macOS 构建与验证

## 构建

- 原生 SwiftUI / AppKit 界面，AVFoundation 透明视频，原生 Canvas 图表与液体按钮。
- `.app` 包含 `arm64`、`x86_64` 两种架构，最低 macOS 14。
- 两个架构均编译通过；本机 Apple Silicon 实际运行通过。
- Swift Package release 构建通过，可使用 Xcode 打开源码。
- Info.plist 校验和本地 ad-hoc 代码签名完整性校验通过。

## 功能测试

45 项原生功能断言通过：

- 初始模式、真实截止时间、开始 / 暂停、重置、当前模式修改后的计时和视频重置联动。
- 模式重命名、时长和名称校验、提示音、最多五个模式、唯一默认名称及最后一个模式保护。
- 专注完成记录、四轮长休息、自定义专注后休息及返回原模式。
- JSON 保存恢复、运行中重新启动、已过期计时只结算一次、损坏数据回退。
- 今日次数 / 分钟 / 平均、本周从周一累计、未来日期空值与空记录。

计时测试采用可控时钟，未等待真实25分钟或执行整机休眠测试。

## 动画与视觉保真

50项保真断言覆盖CSS贝塞尔曲线、分组延迟、导航中途反向、设置退出时连续切页、JS弹簧积分、SVG液体合成与暗色描边、按钮颜色过渡、图表cubic进度、sRGB透明处理和WebAudio提示音包络。详见 `parity-validation.json`。

## 媒体

六段 HEVC-with-Alpha 视频均经 AVFoundation 实际解码：

- 540×720，60fps。
- 透明边角和不透明人物内容有效。
- 约12.5–21.82秒，保留此前烘焙的慢动作节奏。
- 寻帧及播放层未就绪时保留原型共用海报；寻帧完成且播放层就绪后隐藏静态海报，避免透明人物叠加重影；层未就绪时显示同姿态海报。
- 图标由原SVG转为PDF矢量，并验证开放轮廓没有被意外闭合填充。

详细数据见 `media-validation.json`。
