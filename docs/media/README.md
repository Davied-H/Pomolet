# Pomolet showcase

- `pomolet-demo.mp4`: 53.5 seconds, 1280 × 960, 60fps, H.264 / YUV420p, silent, MP4 fast-start.
- `pomolet-preview.gif`: an eight-second animated README preview.
- `pomolet-demo-poster.jpg`: still cover.

Recorded from the native Pomolet application using ScreenCaptureKit window capture. The same release binary runs with isolated sample settings/history. No desktop or other apps are recorded. Idle gaps are trimmed; the UI animations remain at their original speed. English captions and short dissolves introduce the seven sections: focus, short break, long break, statistics, settings, appearance and continued focus.
