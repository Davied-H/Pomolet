# Pomolet showcase

- `pomolet-demo-en.mp4`: 52.23 seconds, 1280 × 960, 60fps, H.264 / YUV420p, silent, MP4 fast-start.
- `pomolet-preview-en.gif`: an eight-second animated README preview.
- `pomolet-demo-en-poster.jpg`: still cover.

Default GitHub showcase: English interface, English task and English sample history.

Recorded from the native Pomolet application using ScreenCaptureKit window capture. The same release binary runs with isolated sample settings/history. No desktop or other apps are recorded. Idle gaps are trimmed; the UI animations remain at their original speed. English captions and short dissolves introduce the eight sections: focus, short break, long break, statistics, settings, appearance and continued focus.
