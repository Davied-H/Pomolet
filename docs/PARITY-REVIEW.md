# HTML 与 macOS 原生版对照复核

基准：当前 `outputs/pomodoro.html` 的最终 CSS 覆盖、JavaScript 行为及现有媒体。三个 agent 分别复核视觉布局、业务/键盘行为、媒体与动画；主代理整合并验证。

## 本轮修复

- 盒模型改为 390×420 外框、388×418 内容区，校正 1px 原点、336px 控件宽度、人物与计时坐标、滑块尺寸、字体字重/字距、空态和设置间距。
- 统计与设置使用各自分组时序，移植 CSS 贝塞尔曲线、进退场延迟、齿轮旋转和入口选中态；快速反向接续当前状态。实操额外发现并修复设置退出期间切统计时残留遮挡的问题。
- 水滴按网页同一弹簧积分推进，完整实现 Gaussian → Alpha 矩阵 → SourceGraphic atop 合成，保留暗色描边；按钮填充/描边 200ms、文字 180ms 连续变色。
- 顶部通知按实际文本尺寸滑入；声音提示 tooltip 独立过渡；图表按 JS cubic ease-out 绘制。
- 六段透明视频保留模式专属随机动作，寻帧时使用共用海报，避免空帧和叠影；暗色转换改为 sRGB 与 Alpha 一致处理。
- 提示音包络对齐 WebAudio 的攻击、指数衰减及尾段保持。
- 隐藏页面与沉浸时退场控件禁用键盘焦点；菜单方向键、Tab 顺序及分钟步进对齐网页。
- 自动保存错误按字段恢复，不被其他编辑清除；自定义专注后的休息跨重启仍返回原模式。

## 检查边界

原型浏览器页面未能实播，未完成浏览器与原生逐像素自动差分。对照基于源码与已有截图，原生系统字体和浏览器光栅化仍可能出现细微差异，因此不能声称已经证明所有像素完全相同。Intel 版本编译验证，本机实操使用 Apple Silicon。

测试数、媒体结果及原生实操记录见 `VALIDATION.md`、`parity-validation.json` 与 `media-validation.json`。测试样例使用独立 QA 数据，不写入正式记录。
